## How I use AI

- **The right model for each task:** a large one where the quality of the answer matters, a small one for extracting data.
- **Controlled outputs:** fixed schemas, limits per user and per request, and a person reviews before anything is published.
- **Claude Code with rules:** project rules, and a security review before any change to the database or authentication.
