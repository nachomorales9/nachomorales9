# Ignacio Morales

AI Developer in Buenos Aires. I build web and mobile products with language models inside: assistants, image reading and audio transcription.

## Featured work

- **Trevsi**: a mobile photo game for trips with friends. React Native, Expo, Supabase. Beta.
- **Nodo**: a sales assistant. Claude talks with visitors and a second model saves each lead to the CRM. Next.js, Anthropic SDK.
- **Atlas del Sabor**: recipes written with Llama over a hand-curated list, plus recipes from a photo. Next.js, Supabase, Groq.
- **Estúdiate**: a study app that summarizes notes, reads photos and transcribes lectures with Whisper. React, Supabase, Groq.
- **Fulbazo**: a World Cup 2026 platform with predictions, rankings and live chat. Supabase, Clerk, Mercado Pago.

## How I use AI

Right model for each task, structured outputs, limits per user and per response, and human review before publishing. I build with Claude Code using project rules.

## Stack

TypeScript · React · Next.js · React Native · Expo · Supabase · PostgreSQL · Claude API · Groq · Vercel
