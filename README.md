## Cómo trabajo con IA

- **El modelo justo para cada tarea.** Uno grande donde importa cómo responde, uno chico donde la tarea es mecánica, y ninguno donde alcanza una regla.
- **Límites desde el principio.** Respuestas con esquema fijo, la clave en el servidor, topes por persona y por respuesta, modelo de reemplazo y revisión humana antes de publicar.
- **Claude Code, usado con método.** `CLAUDE.md` y reglas por área, subagentes propios de solo lectura (arquitectura, seguridad y revisión de código), skills y plugins. La decisión final, las credenciales y los deploys son míos.
- **Probado antes de publicar.** Tests, pruebas de permisos en la base de datos y CI en cada push.
